# Esercizi SQL

Raccolta di script SQL per esercitarsi con creazione di tabelle e query.

## Contenuti

| File | Argomento |
| --- | --- |
| `esercizi/EducationalGames.sql` | Schema e query su un database di giochi educativi |
| `esercizi/esercizi_multe/struttura_base.sql` | Creazione delle tabelle di base per l'esercizio sulle multe |
| `esercizi/esercizi_multe/query.sql`, `query2.sql` | Query da svolgere sul database delle multe |

## Come eseguire

Importa lo script `struttura_base.sql` (o `EducationalGames.sql`) nel tuo DBMS preferito (es. MySQL, MariaDB, phpMyAdmin) per creare le tabelle, poi esegui i file di query per esercitarti.
