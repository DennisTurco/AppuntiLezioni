# Flowchart

Diagrammi di flusso (`.fprg`) usati per introdurre la logica di programmazione prima di scrivere codice vero e proprio.

## Contenuti

- `chart_calcolatrice.fprg`, `chart_calcolatrice2.fprg` — logica di una calcolatrice
- `chart_ordinamentoArray.fprg` — ordinamento di un array
- `chart_ricercaMax.fprg` — ricerca del massimo in un array

## Come aprire i file

I file `.fprg` si aprono e si eseguono passo-passo con [Flowgorithm](http://www.flowgorithm.org/), un programma gratuito per creare ed eseguire diagrammi di flusso.
