# Materiale di Matematica

Dispense ed esercizi di matematica in formato PDF, con alcuni file sorgente **Xournal++** (`.xopp`) usati per annotare gli esercizi durante le lezioni.

## Contenuti

| Cartella | Argomento |
| --- | --- |
| `1 Superiore/` | Equazioni di secondo grado, scomposizioni, retta nel piano cartesiano, geometria, idrostatica |
| `disequazioni/` | Disequazioni di secondo grado |
| `limiti/` | Limiti |
| `asintoti/` | Asintoti |
| `studi-di-funzione/` | Studio di funzione |
| `derivate/` | Derivate |
| `circonferenza/` | Circonferenza |
| `trigonometria/` | Trigonometria |
| `esame-maturita/` | Esercizi in stile esame di stato (retta e sfera, simulazioni) |

## Note

- I PDF si aprono con qualsiasi lettore.
- I file `.xopp` richiedono [Xournal++](https://xournalpp.github.io/) per essere aperti e modificati; per ogni `.xopp` è presente il relativo PDF esportato, consultabile senza installare nulla.
