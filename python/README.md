# Esercizi Python

Raccolta di esercizi e lezioni di programmazione in Python: dai tipi di dato base alla programmazione a oggetti, fino a piccoli progetti.

## Contenuti

| Cartella | Argomento |
| --- | --- |
| `esempi_corso_start2data/` | Esempi introduttivi: variabili, `if/else`, cicli, liste, dizionari, set, funzioni, lambda, file, gestione eccezioni, classi |
| `classi/` | Programmazione a oggetti |
| `ereditarietà/` | Ereditarietà singola e multipla |
| `static_method/` | Metodi statici |
| `gestione_eccezioni/` | Eccezioni, incluse eccezioni personalizzate |
| `file/` | Lettura e scrittura su file |
| `json/` | Lettura/scrittura di file JSON |
| `logging/` | Modulo `logging` |
| `keyboard/` | Gestione input da tastiera (libreria `keyboard`) |
| `esercizi/` | Esercizi vari (dizionari, riempimento) |
| `esami_universitari/` | Tracce d'esame (Esame1-4) |
| `progetti/DonkeyKong/` | Mini-progetto: gioco ispirato a Donkey Kong |

## Come eseguire

```bash
python nome_file.py
```

Alcuni esempi (`esempi_corso_start2data/`, `progetti/DonkeyKong/`) potrebbero richiedere pacchetti aggiuntivi: se presente un ambiente virtuale (`.venv`) attivalo prima di eseguire, oppure installa le dipendenze mancanti con `pip install <pacchetto>`.
