# Esercizi HTML

Piccoli esercizi di HTML (e JavaScript base) per prendere confidenza con form, eventi e struttura di una pagina.

## Contenuti

| File/Cartella | Argomento |
| --- | --- |
| `lezione_introduttiva.html` | Struttura base di una pagina HTML |
| `form_alert.html` | Form e gestione di eventi con `alert` |
| `calcolo_eta.html` | Calcolo dell'età a partire da un form |
| `calcolatrice.html`, `calcolatriceV2.html` | Calcolatrice interattiva (due versioni) |
| `ricettacolo/` | Mini sito di ricette con più pagine collegate tra loro |

## Come eseguire

Apri direttamente il file `.html` nel browser (doppio click, oppure trascinalo in una finestra del browser).
